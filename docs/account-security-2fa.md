# Two-factor authentication (2FA) and account security

Turning on two-factor authentication adds a second check at sign in, so your account stays protected even if your password is shared or guessed.

To enable two-factor authentication:

1. Go to **Settings → Security → Two-factor authentication**.
2. Choose **Authenticator app** and scan the QR code with your authenticator app.
3. Enter the 6-digit verification code from the app to confirm.
4. Save the recovery codes somewhere safe — they are the only way back in if you lose your phone.

You can disable 2FA from the same screen, but we recommend keeping it on for accounts with billing access.
